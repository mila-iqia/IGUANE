# IGUANE: A tool to explore Figures-of-Merit for some GPUs

Supported FoMs:
  - DRAC's [UGR/RGU](https://docs.alliancecan.ca/wiki/Allocations_and_compute_scheduling#Reference_GPU_Units)
  - My own proposal, IGUANE/IGUANA.
